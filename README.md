# Fireworks

🎆 Fireworks Animation


What is this?

This is a simple interactive fireworks animation project made with HTML, CSS, and JavaScript. Click or move your mouse on the canvas to create colourful fireworks!

How does it work?

HTML5 canvas is used for drawing the animation.

JavaScript powers the particle effects and user interactions.

CSS makes sure the canvas fills your browser window.

Features:

Click on the canvas for an explosion!

Move the mouse for a trail of fireworks.

Bright, random colours and realistic particle motion with gravity and friction.

Smooth fading/trailing effect on a black background.

How to Run:

Clone or download this repo.

Open index.html in your browser.

Enjoy and interact!

File Structure:

index.html — Main HTML page

fireworks.js — JavaScript animation logic

style.css — Site styles 

Why I made this:
I wanted a hands-on project to learn JavaScript and animation basics. Fireworks are fun and a great way to practice drawing, user events, and simple physics!

Future Improvements:

1. Add sound effects.

2. Make more firework shapes.

3. Let users change colours, speed, or particle count.
